BSP G6 — инструкции

1. Bluetooth
2. Ресивер 2.4G
3. USB-подключение
4. Настройки геймпада
    Вручную
    • Клик по кнопке, триггеру, бамперу — нажатие
    • Тянуть стик мышью — наклон, клик по стику — L3/R3
    • Клавиши: WASD — левый стик, стрелки — правый, TFGH — крестовина, 1–4 — A/B/X/Y, Q/E — LB/RB, Z/C — LT/RT, V/B — M1/M2, M — режим, Space — Home (удержание 3 с — сопряжение), N — T (держать + стрелки ↑↓ правого стика — вибрация), U — кабель в ПК, J — кабель в зарядку, R — ресивер в USB
    • Снизу: клик по лопаткам M1/M2, клик по краю ручки переключателя сдвигает её
    • Настоящий геймпад управляет моделью через Gamepad API
