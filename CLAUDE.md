# Black Samurai · сайт-инструкция по геймпадам

Сайт поддержки для геймпадов Black Samurai (BSP), которые возит владелец. Главная фишка — интерактивные
**2D**-инструкции: векторные виды геймпада из макетов инструкций, выноски к кнопкам, пошаговые сценарии
(подключение к ПК / Android / iOS / Switch / PS, смена режимов, калибровка, проблемы), подсветка нужной кнопки.

## Откуда что
- Каркас скопирован с сайта поддержки Xprinter `C:\site` (MkDocs Material, GitHub Pages через Actions).
  Удачные решения оттуда можно переносить, но это **отдельный проект** — принтерное содержимое сюда не тащим.
- Исходные инструкции — `manuals/*.pdf` (копия `O:\ИНСТРУКЦИИ\GAMEPADs`). Многие PDF векторные (D8PRO_EN, D10, D11,
  G6PRO, D6DP…) — из них вытаскиваем SVG геймпада через PyMuPDF. `S07_S08_S09.pdf` на первой странице подписан как S11 —
  уточнить у владельца, верный ли файл.
- GameSir X5 Lite и Nova Lite — чужой бренд, который тоже продаётся; на сайте не выдавать за Black Samurai.

## Правила
- **Публикация только после явного «да, отправляй»** от владельца. Push в `main` = публикация.
- Домен будет свой (вариант `bsp` или `bspads`), хостинг — GitHub Pages. Без Cloudflare: аудитория в России,
  Cloudflare там тормозят. Когда домен выбран — `site_url` в mkdocs.yml и Settings → Pages → Custom domain.
- Не публиковать личные данные клиентов, токены и ключи. Токены в чат не вставлять — `gh` логинится через keyring.
- Перед публикацией сайт проверяем локально (`mkdocs serve`) и на ширине телефона.
- Ответы владельцу — по-русски.
